# 用户使用说明书 · H5 公开门户

> 适用端：`https://wx-bwc-api.greathiit.com/h5/`
> 适用对象：访客、家长、公众、师生
> 版本：1.0.0

H5 门户无需安装、无需登录即可浏览公开内容；访客预约、失物登记等业务可直接在线办理。页面同时适配 PC 与手机，支持中英文切换与微信内分享。

---

## 一、访问与导航

### 1.1 地址

- 门户首页：`https://wx-bwc-api.greathiit.com/h5/{学校编码}`，默认 `DEMO`。
- 访客预约：`https://wx-bwc-api.greathiit.com/h5/{学校编码}/visitor`
- 失物招领：`https://wx-bwc-api.greathiit.com/h5/{学校编码}/lost`
- 安全资讯：`https://wx-bwc-api.greathiit.com/h5/{学校编码}/news`
- 学校门户：`https://wx-bwc-api.greathiit.com/h5/{学校编码}/school`

将 `{学校编码}` 替换为学校提供的编码（如 `DEMO`）。

### 1.2 顶部导航

- 学校 Logo 与名称。
- 首页、访客预约、失物招领、安全资讯、学校门户。
- 语言切换：中文 / EN。
- 手机端折叠菜单。
- 右下角悬浮「预约」按钮，随时进入访客预约。

导航项由后台「菜单配置」的 `h5` 菜单驱动，学校可自定义名称与顺序。

### 1.3 页脚

展示学校名称、值班电话、服务域名与版权信息；值班电话来自租户配置。

## 二、门户首页

### 2.1 首屏

- 学校名称与安全理念简介。
- 「访客预约」「失物招领」主按钮。
- 数据概览：安全资讯数量、待认领物品、24 小时值班。
- 门禁通行、24 小时巡逻状态标识。

### 2.2 快捷服务

四张卡片：

| 卡片 | 功能 |
|---|---|
| 访客预约 | 在线提交来访申请，审批后凭码入校 |
| 失物招领 | 浏览待认领物品，登记拾获信息 |
| 安全资讯 | 安全动态、通知公告、防范提示 |
| 学校门户 | 学校安全体系介绍与联系方式 |

### 2.3 公告与预警

- 最新公告：标题、分类、摘要、发布时间、浏览量，点击查看详情。
- 安全预警：诈骗、暴雨、风险提示，展示前 3 条。
- 失物展示：最新待认领物品，点击进入失物页。

## 三、访客公开预约

### 3.1 填写预约

无需注册，直接填写：

| 字段 | 必填 | 说明 |
|---|---|---|
| 访客姓名 | 是 | 最多 30 字 |
| 手机号 | 是 | 11 位 |
| 身份证号 | 否 | 18 位，加密存储，页面仅显示掩码 |
| 被访人 | 否 | 姓名 |
| 来访事由 | 是 | 公务/家长/学术/面试/物流/其他 |
| 随行人数 | 否 | 0–20 |
| 来访时间 | 是 | 日期 + 时间 |
| 离校时间 | 否 | 日期 + 时间 |
| 车牌号 | 否 | 如 京A12345 |
| 备注 | 否 | 最多 200 字 |

### 3.2 提交与结果

1. 点击「提交预约」。
2. 成功页展示预约号、访客姓名、手机号/身份证掩码、来访时间、状态「待审批」。
3. 提示「身份证号加密存储，页面仅展示脱敏信息」。
4. 可「再次预约」或返回首页。

### 3.3 审批与入校

- 被访人收到提醒后审批。
- 审批通过后凭通行码在预约时段入校。
- 门岗扫码/输入通行码核验；过期、已使用、黑名单会拦截。
- 未收到结果可联系被访人或学校值班电话。

### 3.4 预约流程

```text
在线提交 → 被访人审批 → 生成通行码 → 门岗核验 → 入校
```

### 3.5 注意事项

- 请按预约时段到校，配合门卫核验。
- 身份证号仅用于身份核验，不对外展示完整值。
- 重复提交会被防重/限流拦截。
- 体温异常、涉疫要求等按学校现场规定执行。

## 四、失物招领

### 4.1 浏览失物

- 关键词搜索物品名称/地点。
- 分类筛选：电子产品、证件卡类、衣物、书籍资料、其他。
- 卡片展示照片、名称、分类、地点、拾获时间、编号、存放位置。
- 点击查看详情与描述。

### 4.2 登记拾获物品

1. 点击「+ 登记拾获」。
2. 填写物品名称（必填）、分类、地点、描述、拾获人、存放位置。
3. 提交成功获得登记编号。
4. 请将物品交至保卫处失物招领点，方便失主认领。

### 4.3 失物公告

页面下方展示失物招领公告，含标题、内容、发布时间。

### 4.4 认领

公开页支持浏览与登记；认领需核验身份，请联系保卫处或使用小程序/公众号提交认领申请，按通知到指定地点领取。

## 五、安全资讯

### 5.1 列表

- 公告分类、标题、摘要、发布时间、浏览量。
- 支持分页/加载更多（按实现）。
- 点击进入详情。

### 5.2 详情

- 富文本正文、图片、视频。
- 标题、发布时间、浏览量。
- 可分享到微信会话/朋友圈（受微信规则限制）。

### 5.3 预警

首页与资讯页展示安全预警，内容来自后台「温馨提示」，已发布状态才对外可见。

## 六、学校门户

- 学校安全体系介绍：门禁访客、车辆识别、消防管理、巡逻应急。
- 值班电话、学校编码、运行状态。
- 快捷入口：访客预约、失物招领、安全资讯。

## 七、分享落地页

链接格式：`/h5/{学校编码}/share/{type}/{id}`

| type | 内容 |
|---|---|
| visitor | 访客预约摘要 |
| lost | 失物详情 |
| warning | 安全预警/资讯 |

- 微信内直接打开，展示标题、描述、来源标识。
- 未登录可查看公开信息；办理业务时按提示登录/填写。
- 分享链接不包含完整身份证号、手机号等敏感信息。

---

## 八、多语言与 SEO

- 右上角「EN / 中文」切换，立即生效并记住选择。
- 页面根据语言设置标题、描述、`hreflang`，便于搜索引擎收录。
- 支持 PC 与移动端自适应；微信内置浏览器可正常打开。
- 分享卡片使用学校名称、简介与 Logo。

---

## 九、常见问题

| 问题 | 处理 |
|---|---|
| 页面提示学校不存在 | 检查学校编码是否正确，联系学校获取链接 |
| 预约提交失败 | 检查必填项、手机号格式、时间；是否触发限流 |
| 身份证显示星号 | 正常脱敏，完整值不会展示 |
| 收不到审批结果 | 联系被访人；或拨打学校值班电话 |
| 通行码无效 | 预约是否通过、是否过期、是否已使用 |
| 失物搜不到 | 换关键词/分类，或联系保卫处 |
| 图片打不开 | 刷新页面；检查网络；联系管理员 |
| 切换英文后部分内容仍中文 | 该内容未录入英文翻译，联系学校补充 |
| 微信分享无卡片 | 检查页面 meta、合法域名与微信配置 |

## 十、隐私与安全

- 身份证号、手机号加密存储，公开页面仅展示掩码。
- 预约信息仅用于门岗核验与校园安全管理，不向无关第三方提供。
- 分享链接避免携带敏感字段；截图传播风险由用户自行承担。
- 未成年人信息遵循最小必要原则，需监护人指导使用。
- 发现信息泄露或页面异常，请联系学校保卫处。
