# 用户使用说明书 · 微信小程序（校园端）

> 适用端：微信小程序「校园保卫」
> 适用对象：师生、家长、访客、被访人、保安
> 版本：1.0.0
> 合法域名：`wx-bwc-api.greathiit.com`

---

## 一、进入与登录

### 1.1 打开小程序

- 微信搜索学校提供的「校园保卫」小程序，或扫描学校公告/二维码进入。
- 首次进入可浏览公开内容（首页、安全资讯、失物墙、访客预约）。
- 使用审批、我的预约、消息、学习考试等完整功能需登录。

### 1.2 微信授权登录

1. 点击「我的 → 立即登录」或页面登录按钮。
2. 允许微信授权。
3. 首次使用需绑定学校档案：输入账号、密码（由学校分配），完成绑定。
4. 绑定后再次进入自动登录；UnionID 已打通时，小程序、公众号、App 可互通。

> 未绑定档案时，系统提示「微信账号尚未绑定本校档案」，按提示使用账号密码绑定即可。

### 1.3 账号与隐私

- 账号由学校统一分配，忘记密码请联系保卫处或管理员重置。
- 身份证号、手机号加密存储，页面仅展示掩码。
- 首次使用请阅读《用户协议与隐私政策》，特别是未成年人个人信息保护条款。

## 二、首页

### 2.1 内容区

- 顶部学校名称与欢迎语。
- 数据卡片：今日访客、待审预约、未闭环隐患、今日巡逻打卡（有权限时显示）。
- 安全预警：诈骗、暴雨、风险提示。
- 快捷服务：访客预约、车辆预约、失物招领、报修反馈、安全教育、审批、消息等（按后台菜单配置）。
- 安全资讯：公告列表，点击查看详情。
- 访客通行码核验入口。

### 2.2 tabBar

底部默认五个入口：首页、访客、失物、消息、我的。tabBar 文案与顺序由后台「菜单配置」维护，刷新即生效，无需重新发版。

## 三、访客预约

### 3.1 发起预约

1. 首页「访客预约」或底部「访客」→「新增预约」。
2. 填写：
   - 访客姓名（必填）
   - 手机号（必填，11 位）
   - 身份证号（选填，仅用于核验，加密存储）
   - 来访事由（必选）
   - 来访日期/时间（必填）
   - 离校日期/时间（选填）
   - 被访人（姓名或选择）
   - 随行人数
   - 车牌号（选填）
   - 备注
3. 提交，页面展示预约结果与脱敏信息。

### 3.2 查看与通行码

- 「访客」页查看我的预约与状态：待审批、已通过、已驳回、已取消、已通行。
- 审批通过后展示通行码二维码与有效期。
- 到校时向门岗出示二维码，或由门岗输入通行码核验。
- 过期、已使用、黑名单会提示无法通行。

### 3.3 审批结果通知

- 被访人审批后，通过订阅消息/站内消息通知。
- 未收到通知可在「消息」中查看。

### 3.4 被访人审批

被访人/教职工登录后，在「审批」页处理访客预约：

- 查看访客姓名、事由、时间、随行人数。
- 「通过」或「驳回」；驳回建议填写原因。
- 审批结果同步给访客。

### 3.5 注意事项

- 预约需在允许的提前时限内提交（平台参数控制）。
- 同一访客短时间内重复提交会被防重/限流拦截。
- 身份证号仅提交时使用，页面不回显完整号码。

## 四、车辆预约

1. 首页「车辆预约」。
2. 填写车牌号、车主/访客姓名、手机号、来访时间、事由、被访人。
3. 提交后等待审批。
4. 审批通过后系统自动向车牌识别相机下发临时车牌，有效期内自动放行，到期自动失效。
5. 在「我的预约」查看状态；下发失败可联系保卫处重试。

> 校内长期车辆备案由保卫处后台维护，不在小程序自助办理。

---

## 五、失物招领

### 5.1 失物墙

- 底部「失物」查看已发布失物。
- 支持按分类筛选、按名称/地点搜索。
- 卡片展示物品图片、名称、分类、地点、拾获时间、状态。

### 5.2 查看详情与认领

1. 点击失物卡片查看详情、照片、存放地点。
2. 点击「申请认领」，填写认领人、联系方式、特征描述。
3. 提交后等待保卫处核验；核验通过后按通知到指定地点领取。
4. 「我的认领」查看进度：待核验、已通过、已驳回。

### 5.3 登记拾获物品

1. 失物页右下角「＋ 登记」。
2. 填写物品名称、分类、拾获地点、时间、描述、拾获人、存放位置。
3. 提交后生成登记编号，请将物品交至保卫处失物招领点。

### 5.4 隐私

认领信息中的手机号、身份证号仅展示掩码；失物公告不展示完整个人敏感信息。

## 六、报修与反馈

### 6.1 报修

1. 首页「报修反馈」。
2. 选择设备/设施类型，填写位置、故障描述，拍照。
3. 提交生成报修工单，可在消息中查看处理进度。

### 6.2 投诉建议

填写主题、内容、联系方式（选填），提交后由保卫处/后勤处理并回复。处理结果在消息中心查看。

---

## 七、安全教育

### 7.1 课程学习

1. 首页「安全教育」。
2. 选择课程，查看图文/视频内容。
3. 系统记录学习进度；完成学习后可参加考试。

### 7.2 在线考试

1. 进入「安全考试」，选择进行中的考试。
2. 按题目作答，提交后自动判分。
3. 查看成绩、是否及格、错题解析（如配置）。
4. 新生安全教育考试按学校要求完成。

### 7.3 安全资讯

- 首页「安全资讯」或「更多」查看公告、预警、宣传素材。
- 支持图文详情、浏览量统计。

## 八、审批中心

「审批」页按角色展示待办：

| 类型 | 说明 |
|---|---|
| 访客预约 | 被访人/教职工审批 |
| 车辆预约 | 被访人/保卫处审批 |
| 失物认领 | 保卫处核验 |
| 安全报备 | 保卫处审批 |
| 调监控申请 | 分级审批，小程序仅展示进度 |

操作：

- 点击条目查看详情。
- 「通过」/「驳回」；驳回填写原因。
- 调监控需在 PC 后台完成两级审批，小程序提示进度。

无权限时页面提示登录或联系管理员。

---

## 九、消息中心

- 底部「消息」查看站内消息。
- 分类：审批结果、待办提醒、隐患督办、事件分派、失物认领、安全预警、到期提醒。
- 未读红点；点击阅读后标记已读。
- 微信订阅消息需用户授权，未授权时以站内消息兜底。

---

## 十、个人中心

### 10.1 账号信息

展示姓名、账号、手机号（掩码）、身份证（掩码）、部门、角色、学校。

### 10.2 修改密码

1. 「我的 → 修改密码」。
2. 输入旧密码、新密码（8–32 位）、确认新密码。
3. 保存后重新登录。

### 10.3 多语言

「我的 → 语言 / Language」切换简体中文 / English，立即生效。

### 10.4 协议与关于

- 用户协议与隐私政策：含个人信息保护、监控调取审批、数据删除渠道。
- 关于：版本号、服务域名、技术支持。

### 10.5 退出登录

清除本地登录状态；下次进入需重新授权/登录。

## 十一、常见问题

| 问题 | 处理 |
|---|---|
| 无法登录 | 确认账号密码、学校编码；是否已绑定微信 |
| 收不到审批通知 | 检查订阅消息授权；在消息中心查看 |
| 预约提交失败 | 检查必填项、时间是否在允许范围；是否触发限流 |
| 通行码打不开 | 预约是否已通过；是否过期 |
| 失物搜不到 | 换关键词/分类；联系保卫处 |
| 认领被驳回 | 查看驳回原因，补充特征后重新申请 |
| 考试提交失败 | 检查网络；避免重复提交 |
| 页面空白 | 下拉刷新；更新微信版本；联系管理员 |
| 身份证显示掩码 | 正常隐私保护，完整值不展示 |

## 十二、安全提示

- 仅通过学校官方渠道进入小程序，谨防仿冒。
- 不向他人转发通行码、预约二维码。
- 不随意填写他人身份证号、手机号。
- 发现账号异常、信息泄露，立即联系保卫处。
- 未成年人使用需在监护人指导下阅读隐私政策。
