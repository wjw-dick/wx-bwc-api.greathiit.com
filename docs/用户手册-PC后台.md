# 用户使用说明书 · PC 管理后台

> 适用端：`https://wx-bwc-api.greathiit.com/admin/`
> 适用对象：平台超级管理员、租户管理员、保安队长、业务教职工、校领导（只读）
> 版本：1.0.0

---

## 一、登录与界面

### 1.1 登录

1. 浏览器打开 `https://wx-bwc-api.greathiit.com/admin/`。
2. 输入账号、密码，选择租户（租户账号需填写学校编码，如 `DEMO`）。
3. 平台账号直接登录，无需租户编码。
4. 首次登录后请立即在右上角头像菜单中修改密码。

默认演示账号（生产请修改/停用）：

| 账号 | 角色 | 说明 |
|---|---|---|
| `system` | 平台超管 | 全部学校看板、租户管理、平台参数 |
| `demo_admin` | 租户管理员 | 示范中学全量业务 |
| `demo_captain` | 保安队长 | 巡逻、事件、审批 |
| `demo_guard` | 保安 | 一线执勤 |
| `demo_teacher` | 教职工 | 被访人审批 |
| `demo_student` | 学生 | 预约、失物、教育 |
| `demo_leader` | 校领导 | 只读看板 |

统一初始密码 `Admin@123`。

### 1.2 界面结构

- **左侧菜单**：按角色权限动态生成，可折叠；支持平台/租户两套菜单。
- **顶部面包屑**：显示学校名称与当前页面。
- **平台租户切换器**：仅平台账号可见，可搜索学校并切换为「只读下钻」视图。
- **语言切换**：简体中文 / English。
- **消息铃铛**：站内消息，未读红点。
- **头像菜单**：账号信息、修改密码、退出登录。

### 1.3 通用列表操作

- 关键词搜索、状态筛选、重置。
- 新增、详情、编辑、删除（危险操作二次确认）。
- 分页、每页条数切换。
- 图片字段支持缩略图与点击预览。
- 富文本字段使用带工具栏的编辑器，粘贴图片自动上传对象存储。
- 图片上传为独立卡片，支持拖拽、多图、缩略图、调序、放大、删除、进度条。

### 1.4 平台下钻（只读）

平台账号在顶部选择某所学校后：

- 页面出现「下钻租户只读」标识。
- 可查看该校全部业务数据与统计。
- 新增/编辑/删除/审批按钮隐藏或禁用；接口层同样拒绝写入。
- 清空选择即回到「全部学校」视图。

## 二、工作台

`/dashboard` 展示本校核心指标：

- 访客：今日预约、待审批、已通过、累计。
- 车辆：在场车辆、今日入场/出场。
- 事件：未结案、今日新增、累计结案。
- 隐患：未整改、超期、整改率。
- 消防：设施总数、完好率、临期数量。
- 巡逻：今日任务、完成率、按时率。
- 失物：未认领、认领率。
- 报警：今日报警、未处理。

点击指标可跳转对应模块列表。平台账号的「全部学校看板」展示各校对比，可下钻只读。

## 三、平台管理（仅平台超管）

### 3.1 租户管理 `/platform/tenants`

- **开通学校**：填写名称、编码、类型、联系人、到期时间、用户数配额；系统自动初始化管理员、角色与菜单。
- **编辑**：修改名称、联系方式、配额、到期时间。
- **启停**：停用后该校全部用户不可登录，数据保留；启用后恢复。
- **续期**：延长到期时间，记录操作审计。
- **到期策略**：到期前预警，到期自动停用（平台参数控制）。
- **下钻**：进入某校只读视图，查看其业务数据。

### 3.2 全部学校看板 `/platform/dashboard`

- 按学校/时间统计访客量、事件数、隐患整改率、巡逻完成率、消防完好率、失物认领率、报警数。
- 支持跨校对比与下钻；下钻只读。

### 3.3 平台审计 `/platform/audit`

- 检索全部租户的关键操作：登录、越权、审批、导出、调监控、车牌下发、配置变更。
- 支持按时间、用户、模块、动作筛选与导出。
- 审计日志不可删除。

### 3.4 平台参数 `/system/params`

维护全局参数，保存后实时生效：

| 参数 | 说明 |
|---|---|
| 通行码有效期 | 访客通行码有效小时数 |
| 访客预约提前时限 | 最早可提前预约天数 |
| 隐患整改默认限期 | 分派时默认截止天数 |
| 巡逻迟到容忍 | 打卡迟到判定分钟数 |
| 租户到期策略 | 预警天数/自动停用 |
| 消息发送频率 | 防刷阈值 |

### 3.5 全局字典 `/system/dicts`

平台统一维护事件类型、隐患等级、消防设施类型、设备类型、失物分类、报备类型、车牌类型等标准字典。租户只能扩展自定义项，不能修改全局标准。

## 四、系统管理（租户管理员）

### 4.1 用户管理 `/system/users`

- 新增用户：账号、姓名、手机号、角色、用户类型、状态。
- 编辑、停用、重置密码、逻辑删除。
- 配额校验：达到租户用户数上限时禁止新增。
- 支持 Excel 导入/导出；导入模板字段与列表一致。
- 可查看「可被访人」列表，供访客预约选择。

### 4.2 角色权限 `/system/roles`

- 租户内置角色：租户管理员、保安队长、保安、教职工、学生、校领导、被访人。
- 可新增自定义角色并分配菜单。
- 菜单权限与接口权限双重校验；校领导默认只读。
- 修改角色菜单后，用户重新登录生效。

### 4.3 数据字典 `/system/dicts`

- 查看全局标准字典（只读）。
- 新增/编辑/停用本租户扩展项，不影响其他学校。

### 4.4 菜单配置 `/system/menus`

- 左侧菜单树，右侧属性面板，实时预览。
- 可配置 PC 菜单、小程序 tabBar、H5 底部导航、App 导航。
- 支持显示/隐藏、排序、图标、中英文名称、权限标识。
- 保存后各端刷新即生效，小程序无需发版。

### 4.5 多语言 `/system/i18n`

- 启用/停用语言，维护翻译词条。
- 内容字段提供「中/EN」小 tab，未填显示红点提示。
- 前台语言切换器与后台语言列表同步。

### 4.6 对象存储 `/system/storage`

- 先展示本地、S3、阿里 OSS、腾讯 COS、MinIO 五张驱动卡片，选中后才展开表单。
- AK/SK 为密码框，支持眼睛切换；保存后仅显示掩码。
- 必须「连接测试」通过才可保存。
- 切换驱动后，历史图片仍从旧驱动读取，新图片写入新驱动。

### 4.7 微信配置 `/system/wechat`

- 小程序 AppID/AppSecret、公众号 AppID/AppSecret。
- 服务器 URL、Token、EncodingAESKey。
- 密钥加密存储、页面回掩码、保存实时生效并留审计。
- 公众号自定义菜单可一键同步。
- 「素材 / 标签 / 群发 / 订阅消息」页签：
  - 永久素材支持 image/voice/video/thumb 上传、列表与删除，单文件不超过 10MB。
  - 粉丝标签支持查看、创建、按 OpenID 批量打标签。
  - 群发支持按标签或全部粉丝发送 text / mpnews，提交前需确认内容审核与授权。
  - 订阅消息支持选择小程序模板、页面路径与 JSON 数据，发送结果即时返回。
- 未配置 AppID/AppSecret 或 IP 白名单未放行时，页面返回明确提示，不影响其他功能。

### 4.8 消息模板 `/system/message-templates`

- 管理公众号模板消息与小程序订阅消息模板 ID。
- 覆盖访客审批、待办审批、隐患督办、事件分派、失物认领、预警、到期提醒。
- 按租户配置，发送限流、失败重试、发送日志可查。

### 4.9 审计日志 `/system/audit`

- 检索本租户登录、越权、审批、导出、配置变更等操作。
- 支持时间范围、用户、模块、动作筛选与导出。
- 调监控、敏感数据查询额外留痕。

### 4.10 租户配置

维护学校名称、Logo、值班电话、公众号/小程序信息、微信支付、通知开关等。保存即时生效，密钥字段加密。

## 五、门禁访客

### 5.1 访客预约 `/visitor/appointments`

- 列表：访客姓名、手机号（掩码）、身份证（掩码）、事由、来访时间、被访人、状态、通行码。
- 新增：保安代录或后台录入，填写姓名、证件、手机、事由、时间、随行人数、车牌、被访人。
- 审批：通过/驳回并填写意见；通过后自动生成临时通行码，通知访客。
- 查看通行码：二维码 + 有效期，可打印。
- 取消预约：状态置为已取消。
- 导出：按状态导出 Excel，敏感字段掩码。

### 5.2 通行记录 `/visitor/records`

- 门岗扫码/人工核对生成的通行台账。
- 支持按姓名、通行码、状态检索。
- 黑名单人员通行会被拦截并提示。

### 5.3 临时入校 `/visitor/temp`

无预约到访由保安代录，登记姓名、事由、被访人、时间、车辆，生成临时通行凭证。

### 5.4 黑名单 `/visitor/blacklist`

登记禁止入校人员，支持证件/手机号脱敏展示；命中时门岗拦截。

### 5.5 重点人员 `/visitor/key-persons`

报备人员台账，记录关注原因、责任单位、有效期。

### 5.6 晚归登记 `/visitor/late-return`

登记学生晚归/不归，推送班主任确认，形成闭环记录。

### 5.7 访客统计 `/visitor/stats`

按时间统计访客量、通过率、时段分布、被访人排行；支持 Excel 导出。

## 六、车辆与车牌识别

### 6.1 车辆备案 `/vehicle/vehicles`

- 登记车牌、车主、类型（校内/教职工/访客/特种）、有效期、联系电话。
- 操作「下发固定车牌」调用厂商接口，逐台回写结果。
- 「注销车牌」调用删除接口并留审计。
- 失败记录可在授权台账查看并重试。

### 6.2 车辆预约 `/vehicle/appointments`

外来车辆预约 → 审批 → 自动下发临时车牌（起止时间）→ 到期相机自动失效。支持失败重试。

### 6.3 违停上报 `/vehicle/violations`

登记违停地点、照片、车牌、劝导记录，可联动车主通知。

### 6.4 进出记录 `/vehicle/logs`

本地车辆进出记录；支持从车牌平台同步日志、查看看场车辆。

### 6.5 停车收费 `/vehicle/fees`

按后台开关启用计费；微信支付未配置时仅记账，不发起支付。

### 6.6 车牌识别配置 `/vehicle/plate-config`

1. 填写 BASE 地址与 API 密钥。
2. 点击「连接测试」，调用厂商 `/api/health`。
3. 仅当测试成功且 `mqtt_connected=true` 时「保存」可用。
4. 保存后密钥加密、页面回掩码、实时生效、写审计。
5. 每个租户独立配置，互不影响。

### 6.7 相机管理 `/vehicle/plate-cameras`

- 登记/编辑/删除相机：`cam_id`、名称、校区、类型、备注、启停。
- `cam_id` 必须与厂商侧一致。
- 支持从厂商同步相机台账。

### 6.8 授权台账 `/vehicle/plate-records`

查看看板下发/删除记录，按车牌、状态筛选；失败记录含厂商返回信息，可重试。

## 七、治安事件

### 7.1 事件工单 `/event/events`

- 上报：事件类型（失窃/纠纷/求助/失物/治安）、地点、描述、紧急度、照片、来源。
- 一键报警/求助：带定位，生成紧急工单。
- 分派：指定保安/值班人员。
- 处置：填写现场处置记录、照片。
- 结案：归档并记录结案时间。
- 防重复提交与限流。

### 7.2 纠纷调解 `/event/disputes`

登记纠纷双方、地点、经过；新增调解记录（调解人、内容、结果）。

### 7.3 报警联动 `/event/alarms`

记录消防/门禁等联动事件，关联事件工单，形成闭环。

## 八、消防管理

### 8.1 设施台账 `/fire/facilities`

- 设施编号、类型、位置、生产/有效期、年检日期、责任人、状态。
- 新增自动生成一物一码；「查看二维码」可下载打印。
- 到期/临期在列表与看板高亮。

### 8.2 扫码巡检 `/fire/inspections`

保安扫码巡检，记录结果、照片；异常可一键转隐患。

### 8.3 隐患整改 `/fire/hazards`

流程：上报 → 分派责任人并设限期 → 提交整改方案/照片 → 验收销号。

- 验收不通过退回重改。
- 超期未闭环自动升级提醒。
- 重大隐患触发预警。
- 可打印整改通知单。

### 8.4 消防演练 `/fire/drills`

登记演练时间、地点、参与人数、签到、总结。

### 8.5 消防培训 `/fire/trainings`

记录培训主题、讲师、时间、参与人数、内容。

### 8.6 违规用电 `/fire/power-checks`

宿舍/办公违规用电核查，记录位置、情况、照片、处理结果。

### 8.7 消防报警 `/fire/alarms`

记录报警类型、位置、设备、时间、联动事件、处理状态。

## 十、失物招领

### 10.1 失物登记 `/lost/items`

登记物品名称、分类、地点、时间、照片、描述、拾获人、存放位置；自动生成编号。

### 10.2 失物公告 `/lost/notices`

未认领物品定期处置（归档/销毁），提交申请 → 审批 → 留档。

查看认领率、分类分布、未认领数量。

## 十二、报备审批

### 12.1 安全报备 `/report/applies`

类型：大型活动、施工、动火作业、学生外出/集体实践、危化品入校、条幅/展板点位。

流程：线上提交 → 保卫处审批 → 生成电子回执 → 留档。可打印审批单。

### 12.2 调监控申请 `/report/monitor-access`

流程：师生申请（时间/区域/事由）→ 保卫处初审 → 校领导终审 → 调取登记 → 结果反馈。

- 敏感操作额外鉴权并留痕。
- 审批记录不可删除。
- 支持按状态筛选与导出。

## 十五、后勤管理

### 15.1 排班管理 `/logistics/schedules`

配置保安班次、日期、岗位、人员；移动端可查看本人排班。

### 15.2 考勤记录 `/logistics/attendance`

查看打卡记录、迟到/缺勤；支持补录与统计。

### 15.3 绩效管理 `/logistics/performance`

登记绩效月份、人员、分值、说明，支持汇总。

### 15.4 投诉反馈 `/logistics/feedback`

接收师生投诉/建议 → 分派处理 → 回复闭环；支持满意度记录。

## 十六、报表中心

### 16.1 租户报表 `/report-center/tenant`

访客、车辆、车牌识别、事件、隐患、消防、巡逻、失物、报备等统计；多维筛选 + Excel 导出。

### 16.2 全部学校报表 `/report-center/platform`

跨校统计与对比，支持下钻只读。

### 16.3 月报季报 `/report-center/monthly`

自动生成治安/消防/访客月报，支持 PDF 下载与打印。

## 十七、打印

| 单据 | 入口 |
|---|---|
| 访客通行码 | 访客预约 → 查看通行码 / 打印 |
| 报备审批单 | 安全报备 → 打印审批单 |
| 隐患整改通知单 | 隐患整改 → 整改通知单 |
| 失物标签 | 失物登记 → 打印标签 |
| 月报 | 月报季报 → PDF |

PDF 需要服务器安装中文字体（`BWC_PDF_FONT`），缺失时会提示联系管理员。

## 十八、常见问题

| 问题 | 处理 |
|---|---|
| 登录提示租户停用 | 联系平台续期/启用 |
| 菜单看不到 | 角色未分配菜单，联系管理员 |
| 按钮灰色/403 | 权限不足或处于只读下钻 |
| 上传失败 | 检查文件大小（≤20MB）与网络 |
| 通行码无效 | 已过期/已使用/黑名单，查看通行记录 |
| 车牌保存按钮不可用 | 先完成连接测试且 MQTT 已连接 |
| 下发失败 | 查看授权台账失败原因，检查相机与厂商网关 |
| PDF 乱码/失败 | 服务器缺中文字体，联系运维 |
| 修改密码后仍能操作 | 客户端需清除旧令牌并重新登录 |

## 十九、安全建议

- 首次登录立即修改默认密码。
- 平台账号与租户管理员分开使用，不共享账号。
- 离岗人员及时停用，定期审查高权限角色。
- 导出含个人信息的数据后妥善保管，禁止外传。
- 发现越权提示或异常登录，立即联系保卫处与运维。
