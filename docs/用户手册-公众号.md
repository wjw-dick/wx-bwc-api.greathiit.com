# 用户使用说明书 · 微信公众号（服务号）

> 适用端：微信公众号「校园安全服务号」
> 适用对象：师生、家长、访客、保卫处运营人员
> 版本：1.0.0
> 合法域名：`wx-bwc-api.greathiit.com`

---

## 一、关注与进入

### 1.1 关注公众号

1. 微信搜索学校服务号名称，或扫描学校公告/二维码关注。
2. 关注后自动收到欢迎语：

```text
欢迎关注校园安全服务号！
回复【访客】预约入校，回复【失物】查看失物招领，
回复【报修】提交设备报修，回复【考试】进入安全考试。
```

3. 底部菜单由学校配置，通常包含：校园门户、访客预约、失物招领、安全教育、更多服务。

### 1.2 账号互通

- 公众号网页授权使用 `snsapi_userinfo`，获取 UnionID。
- 同一开放平台下，小程序、公众号、独立 App 绑定同一 UnionID，实现多端登录互通。
- 首次使用需在网页/小程序内绑定学校账号；未绑定时可浏览公开内容。

> UnionID 互通依赖微信开放平台绑定与认证服务号，未配置时系统提示使用账号密码登录。

## 二、菜单与网页服务

### 2.1 菜单结构（示例）

| 一级菜单 | 二级菜单 | 跳转 |
|---|---|---|
| 校园门户 | - | H5 首页 `/h5/{学校编码}` |
| 访客预约 | - | H5 访客预约 `/h5/{学校编码}/visitor` |
| 更多服务 | 失物招领 | H5 `/h5/{学校编码}/lost` |
| 更多服务 | 安全课堂 | H5 安全教育 |
| 更多服务 | 个人中心 | H5/小程序 |

菜单点击后在微信内置浏览器打开 H5，页面自适应手机；支持分享到会话。

### 2.2 网页授权

1. 用户点击菜单进入 H5。
2. 公众号发起网页授权，获取 code。
3. 后端换取 openid/unionid，匹配学校档案。
4. 已绑定用户自动登录；未绑定引导账号密码绑定。
5. 授权失败时降级为公开浏览，并提示原因。

### 2.3 分享落地页

- 访客预约、失物、预警链接可在微信内直接打开。
- 分享链接携带来源标识，落地页展示对应业务摘要。
- 未登录用户可查看公开信息，办理业务时再登录。

## 三、关键词自动回复

在公众号对话框回复关键词：

| 关键词 | 回复内容 |
|---|---|
| 访客 | 访客预约入口与链接 |
| 失物 | 失物招领公告入口 |
| 报修 | 设备报修入口 |
| 考试 | 安全教育课程与考试入口 |
| 其他 | 服务引导与关键词提示 |

- 关键词匹配为包含匹配，大小写不敏感。
- 自动回复即时返回，不消耗人工客服。
- 所有回调消息写入发送日志，便于排查。

## 四、消息通知

### 4.1 通知场景

| 场景 | 接收人 | 内容 |
|---|---|---|
| 访客预约审批 | 被访人/访客 | 待审批提醒、审批结果、通行码 |
| 车辆预约审批 | 被访人/车主 | 审批结果、临时车牌有效期 |
| 隐患督办 | 责任人 | 整改任务、限期、超期提醒 |
| 事件分派 | 处置人 | 事件编号、地点、紧急度 |
| 失物认领 | 失主/拾获人 | 匹配提醒、认领结果 |
| 安全预警 | 师生/家长 | 诈骗、暴雨、风险提示 |
| 到期提醒 | 管理员/责任人 | 消防设施、设备年检、通行码、临时车牌 |

### 4.2 模板消息

- 由学校在后台「消息模板」配置模板 ID。
- 发送时填充业务字段（姓名、时间、地点、状态、备注）。
- 点击消息可跳转 H5/小程序详情页。
- 发送失败自动重试，并记录发送日志；仍失败时降级为站内消息。

### 4.3 订阅消息

- 小程序端需用户主动授权订阅。
- 公众号模板消息不受订阅限制，但需用户关注且模板已配置。
- 未关注/未授权/模板缺失时，系统明确提示并落站内消息。

### 4.4 发送频率与防刷

- 同一用户同一业务节点短时间重复触发会被限流。
- 失败重试有次数上限，避免雪崩。
- 发送日志包含渠道、模板、接收人、状态、失败原因。

## 五、内容与素材

学校可通过以下方式维护公众号内容：

- **图文素材**：在微信公众平台后台创建图文，配置到自定义菜单或群发。
- **安全资讯**：在 PC 后台「安全宣传 → 通知公告/温馨提示」发布，H5 与小程序同步展示，可将链接放入公众号菜单。
- **宣传素材**：在 PC 后台「宣传素材」维护海报、视频，供各端引用。

> 公众号原生图文素材、粉丝标签与群发能力以微信公众平台后台为准；系统负责业务消息、菜单同步与 H5/小程序内容联动。涉及群发前请遵守微信运营规范与学校宣传审批制度。

## 六、运营人员配置指南

### 6.1 微信公众平台

1. 认证服务号，获取 AppID/AppSecret。
2. 「设置与开发 → 基本配置」填写服务器 URL：`https://wx-bwc-api.greathiit.com/api/wechat/callback`，Token 与后台一致。
3. 「设置与开发 → 公众号设置 → 功能设置」配置：
   - 业务域名：`wx-bwc-api.greathiit.com`
   - JS 接口安全域名：`wx-bwc-api.greathiit.com`
   - 网页授权域名：`wx-bwc-api.greathiit.com`
4. 「开发 → 接口权限」确认网页授权、模板消息、自定义菜单权限已开通。
5. 将服务器 IP 加入微信白名单（如启用）。

### 6.2 系统后台

1. 登录 PC 后台 →「系统管理 → 微信配置」。
2. 新增/编辑公众号配置：AppID、AppSecret、Token、EncodingAESKey、服务器地址、业务域名、JS 域名。
3. 保存后密钥加密、页面掩码；修改实时生效并留审计。
4. 「公众号菜单同步」粘贴菜单 JSON，点击同步；失败会返回明确原因。
5. 「素材 / 标签 / 群发 / 订阅消息」页签：
   - 永久素材：选择 image/voice/video/thumb 上传，单文件 ≤10MB；列表可查看 `media_id`、更新时间并删除。
   - 粉丝标签：查看/创建标签；粘贴 OpenID（逗号分隔）批量打标。
   - 定向群发：选择标签（留空为全部粉丝）与 text/mpnews，提交前确认内容审核与用户授权；群发不可撤回。
   - 订阅消息：填写 OpenID、小程序模板 ID、页面路径与 JSON 数据，发送结果即时返回。
6. 「消息模板」配置各业务模板 ID。
7. 在 H5/小程序完成一次真实授权与消息发送验证。

## 七、常见问题

| 问题 | 处理 |
|---|---|
| 关注后无欢迎语 | 检查服务器 URL/Token、回调是否可达、是否认证服务号 |
| 关键词无回复 | 检查 Token、回调日志、是否包含关键词 |
| 菜单同步失败 | 检查 access_token、AppID/Secret、菜单 JSON、接口权限 |
| 网页授权失败 | 检查授权域名、AppID、scope、code 是否重复使用 |
| 收不到模板消息 | 是否关注、模板 ID 是否正确、用户是否授权、发送日志 |
| 点击消息打不开 | 检查跳转 URL、H5 路由与合法域名 |
| UnionID 为空 | 开放平台未绑定或用户未关注，检查开放平台配置 |
| 重复收到消息 | 检查业务防重与重试策略 |

## 八、合规提示

- 公众号内容需符合微信运营规范与学校宣传口径。
- 不得群发未经审批的商业广告、涉密信息。
- 收集个人信息遵循最小必要，明示用途与保存期限。
- 未成年人信息需监护人同意，谨慎推送。
- 监控调取、敏感数据查询必须走分级审批并留痕。
