# 用户使用说明书 · 独立 App（Flutter）

> 适用端：Android / iOS「校园保卫」App
> 适用对象：保安、保安队长、管理人员、校领导
> 版本：1.0.0

独立 App 面向保安一线、管理端与校领导，覆盖巡逻打卡、消防巡检、隐患上报、事件处置、审批、看板、消息与离线补传。安装包由学校统一分发，或由技术人员按 `app/README.md` 构建。

---

## 一、安装与首次启动

### 1.1 安装

- Android：安装学校提供的 APK，或在应用市场搜索学校指定名称。
- iOS：通过 TestFlight/企业分发/App Store 安装（按学校发布方式）。
- 首次启动允许通知、定位、相机权限；拒绝会影响打卡、扫码、拍照。

### 1.2 登录

1. 输入账号、密码、学校编码（如 `DEMO`）。
2. 点击登录；成功后进入首页。
3. 登录状态本地保存，下次自动进入；退出后需重新登录。
4. 支持中英文切换；校领导账号为只读模式。

> 微信 UnionID 绑定能力已预留，当前以账号密码登录为主；绑定接口与小程序/公众号一致。

### 1.3 底部导航

| 页签 | 功能 |
|---|---|
| 首页 | 看板、快捷入口、预警、离线队列 |
| 巡逻 | 路线/点位、GPS/扫码打卡、记录、补传 |
| 事件 | 事件列表、上报、一键报警、处置 |
| 审批 | 访客/车辆/失物/报备/调监控待办 |
| 我的 | 账号、排班、消息、密码、语言、协议 |

## 二、首页看板

- 欢迎语、姓名、角色、部门；校领导显示「只读」。
- 指标卡：今日访客、待审预约、未闭环隐患、今日巡逻打卡、消防告警、未结案事件。
- 快捷入口：巡逻打卡、消防巡检、隐患上报、事件上报，以及后台配置的 `app` 菜单。
- 安全预警列表。
- 离线待补传提示与「立即补传」。
- 下拉刷新。

> 首页快捷入口读取后台「菜单配置 → App 导航」，管理员调整后 App 刷新即生效。

---

## 三、巡逻打卡

### 3.1 选择路线/点位

- 下拉选择路线，点位按排序展示。
- 点位含名称、位置、时间窗。

### 3.2 GPS 打卡

1. 选择点位，点击「GPS 打卡」。
2. 授权定位；系统获取高精度坐标。
3. 定位失败仍可打卡，后台标记缺少坐标。
4. 可填写异常描述。

### 3.3 扫码打卡

1. 点击右上角扫码。
2. 扫描点位二维码。
3. 匹配当前路线点位后自动打卡；不匹配提示错误。

### 3.4 巡逻记录

页面下方展示最近记录：点位、时间、方式、状态。队长可在 PC 查看全量统计。

### 3.5 离线补传

- 网络异常时打卡自动入本地队列（SharedPreferences）。
- 首页/巡逻页显示待补传数量。
- 恢复网络后点击「立即补传」或云上传图标。
- 补传保留原打卡时间；失败条目可重试。
- 不要卸载 App 或清理数据，否则队列丢失。

---

## 四、消防巡检

1. 首页「消防巡检」。
2. 扫码或选择设施，带出编号/位置。
3. 选择「正常/异常」，异常拍照并填写说明。
4. 提交；异常可转隐患。
5. 弱网时自动入队，联网补传。

---

## 五、隐患上报

1. 首页「隐患上报」。
2. 选择等级：一般/较大/重大。
3. 填写位置、描述，拍照。
4. 提交后由后台分派责任人、设定期限。
5. 重大隐患同时电话报告值班队长。

---

## 六、事件接警与处置

### 6.1 事件列表

展示类型、地点、紧急度、状态、时间；支持刷新。

### 6.2 上报事件

选择类型（失窃/纠纷/求助/治安/应急）、紧急度（普通/紧急/特急），填写地点、描述、拍照，提交生成事件编号。

### 6.3 一键报警

1. 点击「一键报警」。
2. 二次确认后向指挥中心发送紧急报警（含定位）。
3. 保持通讯畅通，按指令处置。

> 仅限紧急情况，误报/恶意报警留痕追责。

### 6.4 处置

打开待处置事件 →「处置」→ 填写结果 → 提交。结案由队长/管理员完成。

## 七、审批中心

汇总待办：

- 访客预约
- 车辆预约
- 失物认领
- 安全报备
- 调监控申请（展示进度，两级审批在 PC 完成）

操作：查看详情 → 通过/驳回（驳回填原因）→ 结果通知申请人。

校领导为只读，不显示审批按钮；无权限操作返回 403。

---

## 八、管理端功能

保安队长/管理员可使用：

- 访客审批、车辆审批。
- 隐患整改验收（PC 端更完整）。
- 事件结案。
- 失物处置。
- 调监控审批（PC 端两级）。
- 本校数据看板。
- 消息中心。

校领导：

- 只读查看看板、事件、隐患、巡逻统计。
- 不显示写操作按钮，接口层拒绝写入。

---

## 九、消息与排班

### 9.1 消息

- 首页铃铛或「我的 → 消息」。
- 分类：审批、待办、隐患、事件、失物、预警。
- 未读标记，点击已读。
- 微信推送未配置时以站内消息兜底。

### 9.2 排班

「我的 → 排班」查看本人班次、岗位、日期；由队长在 PC 维护。

### 9.3 考勤

按学校配置在指定时间/地点打卡；异常由队长处理。

---

## 十、个人中心

- 账号信息：姓名、角色、学校、部门、手机号/身份证掩码。
- 修改密码：旧密码 + 新密码（8–32 位）+ 确认；修改后重新登录。
- 语言：简体中文 / English 实时切换。
- 用户协议、隐私政策、版本号。
- 退出登录。

---

## 十一、权限说明

| 权限 | 用途 | 拒绝后果 |
|---|---|---|
| 定位 | 巡逻/隐患打卡定位 | 可打卡但无坐标 |
| 相机 | 扫码、拍照 | 无法扫码/拍照 |
| 相册 | 选择照片 | 无法从相册上传 |
| 通知 | 审批/事件提醒 | 仅站内消息 |

首次使用时逐项授权；可在系统设置中重新开启。

---

## 十二、弱网与离线

- 巡逻、消防巡检支持离线入队。
- 首页显示待补传数量。
- 联网后一键补传，保留原时间。
- 事件上报、审批等需要实时性的操作不建议离线。
- 离线期间不要退出登录/卸载/清理数据。

## 十三、构建与分发（技术人员）

1. 安装 Flutter 3.16+ 与 Android SDK/Xcode。
2. `cd app && flutter pub get`。
3. 首次生成原生工程：`flutter create --platforms=android,ios .`（不会覆盖 `lib/`）。
4. 配置后端地址：
   - 默认 `https://wx-bwc-api.greathiit.com/api`。
   - 可通过 `--dart-define=BWC_BASE_URL=...` 覆盖。
5. 配置签名、应用名称、图标、隐私政策、权限说明。
6. 构建并分发；应用市场需提供隐私政策与权限清单。

## 十四、常见问题

| 问题 | 处理 |
|---|---|
| 登录失败 | 检查账号、密码、学校编码；账号是否停用 |
| 定位失败 | 开启定位权限与 GPS；到开阔处重试 |
| 扫码黑屏 | 授权相机；重启 App；检查摄像头 |
| 打卡迟到 | 超出时间窗，如实上报 |
| 离线记录未补传 | 检查网络与登录；保留数据联系管理员 |
| 审批按钮不显示 | 角色无权限或校领导只读 |
| 推送收不到 | 检查通知权限、微信绑定 |
| 首页快捷入口变化 | 后台菜单已更新，下拉刷新 |
| 修改密码后需重登 | 正常安全策略 |
| App 闪退 | 更新到最新版本；清理缓存；联系技术支持 |

---

## 十五、安全与纪律

- 不共用账号、不代打卡、不伪造记录。
- 不拍摄传播师生隐私与监控画面。
- 处置以人身安全为先，重大情况先报告。
- 所有操作留痕，如实填写。
- 遗失设备立即联系管理员停用账号。
