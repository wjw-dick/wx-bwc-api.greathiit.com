# 用户使用说明书 · 保安一线端

> 适用端：独立 App（Flutter）· 保安 / 保安队长角色
> 适用对象：门岗保安、巡逻保安、消防巡检员、值班队长
> 版本：1.0.0

本手册面向一线执勤人员，按「上岗前 → 门岗 → 巡逻 → 消防 → 事件 → 交班」的真实工作顺序编写。安装与全角色说明见《用户手册-独立App.md》。

---

## 一、上岗前准备

### 1.1 安装与登录

1. 由管理员提供安装包或应用市场下载「校园保卫」App。
2. 首次打开允许通知、定位、相机权限（用于打卡、扫码、拍照）。
3. 输入账号、密码、学校编码（如 `DEMO`），点击登录。
4. 登录后首页显示学校名称、本人姓名、角色与今日数据。

> 账号由保卫处统一开通；忘记密码请联系管理员重置，或在「我的 → 修改密码」自助修改。

### 1.2 首页看板

首页展示：

- 今日访客、待审预约。
- 未闭环隐患、今日巡逻打卡。
- 消防告警、未结案事件。
- 快捷入口：巡逻打卡、消防巡检、隐患上报、事件上报。
- 安全预警与通知。
- 离线待补传数量（弱网时出现）。

顶部下拉可刷新数据。

### 1.3 底部导航

| 页签 | 用途 |
|---|---|
| 首页 | 看板、快捷入口、预警 |
| 巡逻 | 路线/点位、GPS/扫码打卡、记录 |
| 事件 | 事件列表、上报、处置、一键报警 |
| 审批 | 访客/车辆/失物/报备/调监控待办 |
| 我的 | 个人信息、排班、消息、修改密码、语言 |

## 二、门岗执勤

### 2.1 访客核验

1. 访客出示通行码。
2. 进入「审批」或使用扫码功能读取通行码。
3. 系统校验有效期、是否已使用、是否黑名单。
4. 校验通过生成通行记录；异常给出明确提示。

也可在 PC 后台「门禁访客 → 通行记录」查看全部记录。

### 2.2 临时入校

无预约访客由门岗代录：

1. 进入「审批 → 访客」或请值班室在后台录入。
2. 登记姓名、手机号、事由、被访人、时间、随行人数、车牌。
3. 生成临时通行凭证，提醒访客配合核验。

### 2.3 黑名单与重点人员

- 命中黑名单：系统拦截并提示，禁止放行，立即报告值班队长。
- 重点人员：按预案关注并记录，不公开讨论其信息。

### 2.4 车辆放行

- 校内备案车辆：车牌识别自动放行；异常时人工核对。
- 外来车辆：确认已预约/审批，临时车牌在有效期内。
- 未预约车辆：引导至访客预约或按临时入校流程处理。

## 三、巡逻打卡

### 3.1 选择路线与点位

1. 底部「巡逻」。
2. 选择今日路线。
3. 选择当前点位；点位按排序展示，含时间窗。

### 3.2 GPS 打卡

1. 到达点位后点击「GPS 打卡」。
2. 首次使用允许定位权限。
3. 系统记录时间、经纬度；定位失败仍可打卡，由后台标记缺少坐标。

### 3.3 扫码打卡

1. 点击右上角扫码图标。
2. 扫描点位二维码。
3. 二维码属于当前路线时自动打卡；不属于则提示「二维码不属于当前路线点位」。

### 3.4 异常上报

打卡时可填写异常描述并拍照（如路灯损坏、可疑人员、通道堵塞）。提交后进入巡逻记录，必要时转事件/隐患。

### 3.5 迟到与漏点

- 超出点位时间窗打卡记为迟到。
- 未打卡点位记为漏点。
- 系统按平台参数「巡逻迟到容忍」判定，队长可在 PC/App 查看。

### 3.6 弱网离线

- 网络中断时打卡自动进入本地队列，首页/巡逻页显示待补传数量。
- 恢复网络后点击「立即补传」或右上角云上传图标。
- 补传保留原打卡时间；失败条目会提示，可再次补传。

> 请勿在离线时卸载 App 或清理数据，否则未补传记录会丢失。

## 四、消防巡检

### 4.1 扫码巡检

1. 首页「消防巡检」。
2. 扫描设施二维码，自动带出设施编号、位置、类型。
3. 选择结果：正常 / 异常。
4. 异常时拍照、填写说明。
5. 提交；异常可自动生成隐患工单。

### 4.2 手动选择设施

无法扫码时，可从设施列表选择；设施不在本台账时可按提示提交二维码由后台匹配。

### 4.3 隐患上报

1. 首页「隐患上报」。
2. 选择等级：一般 / 较大 / 重大。
3. 填写位置、描述，拍照。
4. 提交后由后台分派责任人、设定期限。

重大隐患会触发升级预警，请同时电话报告值班队长。

### 4.4 离线巡检

消防巡检同样支持弱网离线入队，联网后补传；照片会在补传时一并上传。

## 五、事件接警与处置

### 5.1 查看事件

底部「事件」展示事件列表：类型、地点、紧急度、状态、时间。

### 5.2 上报事件

1. 点击「上报事件」。
2. 选择类型：失窃、纠纷、求助、治安、应急。
3. 选择紧急度：普通、紧急、特急。
4. 填写地点、描述，拍照。
5. 提交，生成事件编号与工单。

### 5.3 一键报警

1. 事件页点击「一键报警」。
2. 二次确认后立即向保卫处指挥中心发送紧急报警，附带定位。
3. 报警后保持通讯畅通，按指令处置。

> 一键报警仅用于紧急情况，恶意报警将记录审计并追责。

### 5.4 现场处置

1. 打开本人待处置事件。
2. 点击「处置」。
3. 填写处置结果（已控制现场、已联系警方、已送医等）。
4. 提交；需要结案的由队长/管理员在后台操作。

## 六、审批待办

「审批」页汇总：

- 访客预约待审批。
- 车辆预约待审批。
- 失物认领待核验。
- 安全报备待审批。
- 调监控申请待审批。

操作：

- 点击条目查看详情。
- 「通过」/「驳回」，驳回需填写原因。
- 审批结果自动通知申请人（微信/站内）。

> 保安角色通常只处理访客/车辆放行相关待办；报备、调监控由有权限的队长/管理员处理。无权限时按钮不显示或提示 403。

## 七、消息与排班

### 7.1 消息中心

- 首页铃铛或「我的 → 消息」。
- 分类：审批、待办、隐患、事件、失物、预警。
- 未读红点，点击阅读后标记已读。

### 7.2 查看排班

「我的 → 排班」查看本人班次、日期、岗位。排班由队长在 PC 后台维护，调整后刷新即可。

### 7.3 考勤打卡

按排班在指定时间/地点打卡；异常（迟到、缺卡）由队长处理。具体入口以本单位配置为准。

---

## 八、个人中心

- **账号信息**：姓名、角色、学校、部门。
- **修改密码**：输入旧密码、新密码（8–32 位）、确认新密码；修改后重新登录。
- **语言**：简体中文 / English 实时切换。
- **关于/隐私**：查看用户协议、隐私政策与版本号。
- **退出登录**：清除本地令牌。

## 十、常见问题

| 问题 | 处理 |
|---|---|
| 登录失败 | 检查账号密码、学校编码；账号是否停用 |
| 定位失败 | 打开系统定位与 App 权限；到开阔处重试；仍可打卡但无坐标 |
| 扫码无反应 | 允许相机权限；擦拭二维码；改用手动选择 |
| 打卡提示迟到 | 已超出点位时间窗，如实上报队长 |
| 离线记录不补传 | 检查网络与登录状态；保留 App 数据，联系管理员 |
| 审批按钮不显示 | 角色无权限，联系队长 |
| 一键报警误触 | 立即报告指挥中心说明情况 |
| 消息收不到 | 检查通知权限；微信推送需绑定 UnionID |
| 修改密码后无法登录 | 确认新密码 8–32 位；联系管理员重置 |

## 十一、纪律与安全

- 不得将账号借给他人使用，不得代打卡。
- 不得拍摄、传播涉及师生隐私的画面。
- 处置事件以人身安全为先，避免单独进入危险区域。
- 发现重大隐患、火情、治安案件，先报警/报告，再记录。
- 所有操作留痕，请如实填写时间、地点、处置结果。
